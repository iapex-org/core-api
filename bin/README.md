# API REST de IAPEX

Esta es la API REST de IAPEX (Inteligencia Artificial para la búsqueda de pacientes extraviados en instituciones de salud). A continuación, se presentan algunas directrices importantes:

- **Cambios**: No se permiten cambios sin antes consultar al encargado en la elaboración de esta API REST. Cualquier modificación sin autorización será expulsada sin previo aviso.
- **Rama principal**: No se permiten cambios directos en la rama principal. Es preferible crear una rama diferente y pasar el enlace para ver los cambios y verificar si son aceptables.
